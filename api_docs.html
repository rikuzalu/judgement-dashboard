Decision API
Developer Documentation

人間の判断をAPIで取得・管理する。ペアワイズ比較、ランキング、ポリシーチェック、
Trust Scoreによる品質保証まで、すべてをプログラマブルに。

https://api.judgement.ai/v1

API 概要

JUDGEMENT Decision APIはREST APIとして提供され、JSON形式でリクエスト/レスポンスを処理します。すべてのリクエストにはAPIキーによる認証が必要です。

PROTOCOL
REST / HTTPS
FORMAT
JSON
AUTHENTICATION
X-API-Key Header
VERSION
v1 (stable)

Quick Start

3つのステップでDecision APIを使い始められます。

01

APIキーを取得

ダッシュボードからAPIキーを発行します。テスト用キーは即座に利用可能です。

02

最初のリクエスト

curlまたはSDKで最初のペアワイズ比較判断リクエストを送信します。

03

結果を確認

Trust Scoreに基づく品質保証付きの判断結果を受け取ります。

最初のリクエスト例

bash
# ペアワイズ比較判断を作成 curl -X POST https://api.judgement.ai/v1/judge/pairwise \ -H "Content-Type: application/json" \ -H "X-API-Key: jdg_your_api_key_here" \ -d '{ "question": "どちらの回答がより正確で有用ですか？", "option_a": "東京タワーは1958年に完成した電波塔です。", "option_b": "東京タワーは日本を代表するランドマークの一つです。", "criteria": ["accuracy", "helpfulness"], "worker_count": 5 }'

Authentication

すべてのAPIリクエストには X-API-Key ヘッダーが必要です。APIキーはダッシュボードの「設定 > API」から発行できます。

APIキーの種類

種類プレフィクス用途制限
テストキーjdg_test_開発・テスト環境100 req/日
本番キーjdg_live_本番環境プランに準拠
http header
X-API-Key: jdg_live_aBcDeFgHiJkLmNoPqRsTuVwXyZ123456 Content-Type: application/json

Endpoints

POST /judge/pairwise

2つの選択肢を比較し、どちらが優れているかを人間が判断します。LLM出力の品質比較、クリエイティブのA/Bテスト等に最適です。

リクエストパラメータ

パラメータ型必須説明
questionstring必須判断の質問文
option_astring必須選択肢A
option_bstring必須選択肢B
criteriastring[]任意評価基準（accuracy, helpfulness, safety等）
worker_countinteger任意判断するワーカー数（デフォルト: 3、最大: 15）
min_trust_scorefloat任意最低Trust Score（デフォルト: 0.7）
callback_urlstring任意完了時のWebhook URL

レスポンス例

json
{ "id": "jdg_pw_9f8e7d6c5b4a", "status": "completed", "result": { "winner": "option_a", "confidence": 0.87, "consensus_score": 0.92, "votes": { "option_a": 4, "option_b": 1, "tie": 0 } }, "criteria_scores": { "accuracy": { "option_a": 4.2, "option_b": 3.1 }, "helpfulness": { "option_a": 4.5, "option_b": 3.8 } }, "metadata": { "worker_count": 5, "avg_trust_score": 0.84, "completed_at": "2026-03-15T10:30:00Z", "duration_ms": 45200 } }
POST /judge/rank

複数の選択肢をランキング形式で順位付けします。3つ以上の候補からベストを選定するケースに最適です。

リクエスト例

json
{ "question": "以下の要約を品質順にランク付けしてください", "options": [ { "id": "a", "content": "要約テキストA..." }, { "id": "b", "content": "要約テキストB..." }, { "id": "c", "content": "要約テキストC..." } ], "criteria": ["accuracy", "readability", "completeness"], "worker_count": 5 }

レスポンス例

json
{ "id": "jdg_rk_a1b2c3d4e5f6", "status": "completed", "result": { "ranking": [ { "rank": 1, "option_id": "a", "score": 4.6 }, { "rank": 2, "option_id": "c", "score": 3.8 }, { "rank": 3, "option_id": "b", "score": 2.9 } ], "consensus_score": 0.88 } }
POST /judge/policy-check

コンテンツがポリシーに準拠しているかを判断します。AI生成コンテンツの安全性チェック、利用規約準拠の検証等に。

リクエスト例

json
{ "content": "チェック対象のテキストコンテンツ...", "policies": ["safety", "accuracy", "bias"], "severity_threshold": "medium", "worker_count": 3 }

レスポンス例

json
{ "id": "jdg_pc_x1y2z3w4v5u6", "status": "completed", "result": { "compliant": false, "violations": [ { "policy": "accuracy", "severity": "high", "description": "統計データに事実と異なる記述が含まれています", "confidence": 0.91 } ], "overall_score": 0.45, "consensus_score": 0.94 } }
GET /judge/consensus-score

完了した判断タスクの合議スコアを取得します。複数ワーカーの判断がどの程度一致しているかを示す指標です。

リクエスト例

bash
curl -X GET "https://api.judgement.ai/v1/judge/consensus-score?task_id=jdg_pw_9f8e7d6c5b4a" \ -H "X-API-Key: jdg_live_your_key"

レスポンス例

json
{ "task_id": "jdg_pw_9f8e7d6c5b4a", "consensus_score": 0.92, "agreement_matrix": { "full_agreement": 0.80, "partial_agreement": 0.12, "disagreement": 0.08 }, "reliability": "high" }
GET /judge/trust-score

ワーカーまたはタスクのTrust Scoreを取得します。判断データの信頼性を定量的に評価する独自指標です。

リクエスト例

bash
curl -X GET "https://api.judgement.ai/v1/judge/trust-score?task_id=jdg_pw_9f8e7d6c5b4a" \ -H "X-API-Key: jdg_live_your_key"

レスポンス例

json
{ "task_id": "jdg_pw_9f8e7d6c5b4a", "trust_score": { "overall": 0.84, "components": { "consistency": 0.89, "gold_accuracy": 0.92, "response_quality": 0.78, "experience": 0.76 } }, "workers": [ { "worker_id": "w_abc123", "trust_score": 0.91 }, { "worker_id": "w_def456", "trust_score": 0.87 }, { "worker_id": "w_ghi789", "trust_score": 0.82 } ] }

Error Codes

APIはHTTPステータスコードとJSON形式のエラーレスポンスを返します。

エラーレスポンス形式
{ "error": { "code": "INVALID_API_KEY", "message": "提供されたAPIキーが無効です", "status": 401 } }

HTTPステータスコード

200成功。リクエストが正常に処理されました。
201作成成功。判断タスクが正常に作成されました。
400不正なリクエスト。パラメータが不足または無効です。
401認証エラー。APIキーが無効または未指定です。
403権限エラー。このリソースへのアクセス権がありません。
404リソースが見つかりません。指定されたタスクIDが存在しません。
429レート制限超過。リクエスト頻度を下げてください。
500サーバーエラー。しばらく経ってから再試行してください。
503サービス利用不可。メンテナンス中の場合があります。

エラーコード一覧

コードHTTP説明
INVALID_API_KEY401APIキーが無効または期限切れです
MISSING_PARAMETER400必須パラメータが不足しています
INVALID_PARAMETER400パラメータの値が不正です
TASK_NOT_FOUND404指定されたタスクIDが見つかりません
RATE_LIMIT_EXCEEDED429レート制限を超過しています
QUOTA_EXCEEDED429月間クォータを超過しています
INSUFFICIENT_WORKERS503利用可能なワーカーが不足しています
TASK_TIMEOUT408タスクが制限時間を超過しました

Rate Limits

APIの安定性を保つため、プランごとにレート制限が設定されています。制限を超えた場合、429 レスポンスが返されます。

プランリクエスト/分月間タスク上限同時実行
Starter1005,00010
Growth50050,00050
Enterprise無制限無制限無制限

レスポンスヘッダーで残りリクエスト数を確認できます:

response headers
X-RateLimit-Limit: 100 X-RateLimit-Remaining: 87 X-RateLimit-Reset: 1710489600

SDKs

公式SDKを利用して、よりスムーズにAPIを統合できます。

pip install judgement-sdk

JavaScript SDK

npm install @judgement/sdk

COMING SOON

Python SDK プレビュー

python
# pip install judgement-sdk from judgement import JudgementClient client = JudgementClient(api_key="jdg_live_your_key") # ペアワイズ比較を作成 result = client.judge.pairwise( question="どちらの回答が正確ですか？", option_a="回答A...", option_b="回答B...", criteria=["accuracy", "helpfulness"], worker_count=5 ) print(f"勝者: {result.winner}") print(f"合議スコア: {result.consensus_score}") print(f"Trust Score: {result.trust_score}")

JavaScript SDK プレビュー

javascript
// npm install @judgement/sdk import { Judgement } from '@judgement/sdk'; const client = new Judgement({ apiKey: 'jdg_live_your_key' }); // ペアワイズ比較を作成 const result = await client.judge.pairwise({ question: 'どちらの回答が正確ですか？', optionA: '回答A...', optionB: '回答B...', criteria: ['accuracy', 'helpfulness'], workerCount: 5 }); console.log(`勝者: ${result.winner}`); console.log(`合議スコア: ${result.consensusScore}`);
